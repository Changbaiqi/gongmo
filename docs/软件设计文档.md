## 1. 项目概述

### 1.1 项目背景

"工墨"是一款面向自由职业者及小型团队的**工时记录与记账一体化**移动应用。区别于市面上单一功能的计时或记账工具，工墨将两者融合在同一主界面：记账与时钟通过底部导航/左右滑动无缝切换；计时模块按标签收入模式自动生成收入账目；同时提供 GitHub 云备份、通知自动记账、应用锁、统计报表与若干效率工具。

### 1.2 核心特性

1. **记账与计时一体**：主界面底部双页切换（记账 | 时钟），支持左右滑动；记账页内含「记账 / 统计」子切换，时钟页内含「计时 / 统计」子切换。
2. **多模式计时**：正计时支持暂停/继续、横屏全屏沉浸计时；标签可配置 4 种收入模式（普通 / 时薪 / 自统计 / 固定薪资），结束后自动或半自动生成收入账目。
3. **打卡考勤**：上下班打卡，自动统计当日累计打卡时长，不计算薪资。
4. **预算管理**：支持「总预算 + 分类子预算」，结余卡内展示分段进度条与使用率，超支/接近超支变色提醒。
5. **统计报表**：记账统计（周/月/年趋势折线、收支构成环形图、收支结余汇总）与工时统计（日/周/月/年、时长柱状图、标签占比环形图、月历时长热力）。
6. **GitHub 云备份与多设备合并**：按年份分片备份到仓库；上传前先拉取合并，删除墓碑防止已删记录被恢复；支持自动同步、手动备份/恢复、本地 JSON 导出。
7. **通知自动记账**：监听支付宝、微信、招商银行通知，解析金额自动入账（含退款），支持分应用开关与去重。
8. **应用锁**：3×3 图案锁（加盐 SHA-256）+ 指纹/生物识别，返回前台超过 20 秒自动重新锁定。
9. **每日记账提醒**：可配置时间的本地通知提醒。
10. **效率工具**：发票助手、汇率计算器（实时汇率 API）、薪资计算器（五险一金与个税）、秒表（含计次与历史）、时区转换、跨时区重叠时段图。
11. **个性化主题**：8 套 Material 3 配色预设、亮/暗/跟随系统、自定义背景图。

### 1.3 技术选型

### 2.2 架构层次

```
┌──────────────────────────────────────────────────────────┐
│                    UI Layer（Pages / Widgets）            │
│  Splash  Lock  Home  WorkPage  StatsView  WorkStatsView  │
│  Sync  Settings  Finance  More/Invoice/Salary/Exchange   │
│  Stopwatch  TimezoneConverter  TimezoneOverlap           │
├──────────────────────────────────────────────────────────┤
│                 Controller Layer（GetX Rx）               │
│  DashboardController(tag: dashboard)  WorkController     │
│  WorkStatsController  FinanceController  StatsController │
│  SyncController  SettingsController  LockController      │
│  ThemeController                                         │
├──────────────────────────────────────────────────────────┤
│                    Repository Layer                      │
│        WorkRepository        FinanceRepository           │
├──────────────────────────────────────────────────────────┤
│                     Service Layer                        │
│  StorageService（单例，内存缓存 + JSON 落盘）             │
│  GithubSyncService  SyncMerge（纯函数）                   │
│  AutoBookkeepingService（后台引擎 + 主引擎队列协作）       │
│  ReminderService  KeepAliveService                       │
├──────────────────────────────────────────────────────────┤
│               Storage / Platform Layer                   │
│  Documents/gongmo_data/*.json   flutter_secure_storage   │
│  Android: NotificationListenerService / MethodChannel    │
└──────────────────────────────────────────────────────────┘
```

分层规则：

- 页面不直接读写文件，只调用 Controller；Controller 调用 Repository 或 Service。
- `StorageService` 是唯一持久化出口，持有全部实体内存列表，落盘后通过 `onDataChanged` 回调通知 `SyncController`。
- `SyncMerge` 为无副作用纯函数，便于单元测试（见 `test/sync_merge_test.dart`）。
- 自动记账的后台引擎与主引擎通过队列文件 `auto_queue.json` 解耦，避免多引擎同时写数据文件。

## 3. 核心功能设计

### 3.1 启动与初始化

`main.dart` 的 `main()` 顺序：

```
WidgetsFlutterBinding.ensureInitialized()
→ 锁定竖屏 + 透明状态栏
→ initializeDateFormatting('zh_CN')
→ StorageService().init()          // 创建目录、加载 JSON、迁移旧数据、补默认值
→ AutoBookkeepingService.processQueue()  // 处理后台引擎写入的待入账队列
→ Get.put(ThemeController())
→ Get.put(LockController(), permanent: true) → lock.init()
→ Get.put(SyncController())        // 注册 onDataChanged 自动同步引擎
→ ReminderService.init() + scheduleDaily()（若已开启）
→ AutoBookkeepingService.startIfNeeded()
→ runApp(GongMoApp)
```

`GongMoApp` 为 `StatefulWidget` + `WidgetsBindingObserver`：

- 用 `Obx` 监听 `ThemeController`，构建 `GetMaterialApp`（中文 locale、Material 3 亮暗主题、8 预设）。
- 有自定义背景图时通过 `builder` 包一层 `_AppBackground`，把图片铺在所有路由之下。
- 生命周期：`paused/hidden` 记录暂停时间；`resumed` 时若 `LockController.needsRelock` 为真（距上次解锁 > 20 秒）且当前不在 `/lock`、`/splash`，则 `Get.toNamed('/lock')`。

`SplashPage` 只负责展示与分流：动画 1.6s、定时 1.8s 后，`lock.enabled && lock.hasPattern` → `/lock`，否则 → `/`（HomePage）。sakura 主题下叠加樱花飘落。

### 3.2 HomePage 主框架

- **底部导航**：自定义两枚 Tab —— 「记账」（`account_balance_wallet_rounded`）与「时钟」（`timer_outlined`），点击与 `PageView` 双向联动（`animateToPage` 300ms）。
- **AppBar**：标题随 Tab 切换「工墨记账 / 工墨时钟」；右侧为同步状态按钮（同步中旋转 + "备份中"，空闲时跳 `/sync`）与设置按钮（跳 `/settings`）。
- **FAB**：仅在「记账」Tab 的「记账」子页显示，点击弹出「记一笔」底部表单。

**Tab 1 记账页**：顶部「记账 | 统计」胶囊切换（`AnimatedSwitcher` 180ms）：

- 子页「记账」`_buildBookkeeping`：可折叠结余卡 + 进行中计时横幅 + 吸顶筛选行 + 账目列表。
- 子页「统计」：`StatsView`（见 §3.5）。

**Tab 2 时钟页**：直接内嵌 `WorkPage`（见 §3.4）。

### 3.3 记账模块

#### 3.3.1 结余卡

- 数据：`DashboardController.monthIncome/monthExpense`，结余 = 收入 − 支出。
- 视觉：`TiltCard`（加速度计倾斜 3D + 动态高光）+ 毛玻璃（`BackdropFilter`）+ 主色渐变；金额与收支用 `CountUpText` 滚动；`restartKey` 在切回记账页时自增以重播动画。
- 滚动联动：`NotificationListener<ScrollNotification>` 根据滚动比例把卡片做「翻折收缩」（透视 rotateX + 缩放 + 透明度），收缩行（"全部账目"）通过 `SliverPersistentHeader` 吸顶。
- 快捷菜单：账单 / 预算 / 资产管家 / 更多；其中预算进入预算弹窗，更多跳 `/more`，其余提示开发中。
- **预算展示区**（有预算时显示）：分段式进度条（每分类一段，按已用/预算填充，颜色 ≥100% 红、≥90% 橙、其余绿；如设总预算且存在分类预算，追加"其他"段），中央显示已使用百分比，下方 `Wrap` 图例。

#### 3.3.2 预算管理

- 数据来源：`DashboardController.budgets`（`Map<categoryId, double>`）、`categoryExpense`、`totalBudget`。
- 总预算弹窗：输入总预算（留空自动回落为分类预算之和），环形图实时预览使用率；校验总预算不得低于分类预算之和。
- 分类预算弹窗：下拉选择支出分类 + 每月额度；校验金额合法且不得超过剩余总预算。
- 持久化：`StorageService.setDataConfig('budgets' / 'total_budget', ...)`，写入更新时间戳并触发自动同步；`mergeRemoteData` 按 `budgets_updated_at` 取较新一方。

#### 3.3.3 账目流水与筛选

- 筛选：吸顶行左侧显示「全部账目 / x年x月 账目」，右侧日期胶囊打开 `showDatePicker` 选择年月；支持一键清除筛选。
- 列表：按天分组（"今天/昨天/x月x日" + 当日收/支汇总），条目为 `SwipeActionCard`（左滑出现蓝色"修改"、红色"删除"）。
- 条目信息：分类色图标、备注（空则分类名）、分类 · 时间（自动记账条目带「自动」标签）、绿 +/红 − 金额。
- 删除：二次确认后 `FinanceController.deleteEntry`。
- 编辑：底部表单（金额 / 收支类型 / 分类网格 / 备注 / 日期时间），保存调用 `saveEntry`。

#### 3.3.4 快速记账

`Get.bottomSheet` 表单：大号金额输入（autofocus）、支出/收入 pill、分类网格（首格为"分类管理"入口）、备注、日期时间选择；保存调用 `FinanceController.addEntry`。

> 已知实现差异：`finance_page.dart` 的独立记账表单在保存时固定取当前类型第一个分类（chip 选中值未生效），主页 `home_page.dart` 的快速记账/编辑表单使用完整分类选择。文档以此现状为准。

#### 3.3.5 分类管理

- 入口：记账表单分类网格首格。
- 交互：`ReorderableListView` 拖动排序（仅同收支类型内）、点击编辑（名称 + 16 图标 + 10 色调色板/随机色）、删除（至少保留 1 个）、新增。
- 逻辑：`FinanceController.addCategory/updateCategory/deleteCategory/reorderCategory`，变更通过 `categoriesRevision` 驱动界面刷新；删除写墓碑 `category:{id}`。

### 3.4 时钟模块（WorkPage）

页面结构：顶部「计时 | 统计」切换；统计为 `WorkStatsView`；计时子页由「正计时 | 打卡」两个 PageView 页面 + 固定底部「记录」区组成，右上"更多"跳 `/time-more`。

#### 3.4.1 正计时

- **空闲态**：150×150 圆形播放按钮（标签色）；若当日该标签已有时长则显示"今日xx: X小时Y分钟"。打卡进行中时禁用正计时。
- **运行态**：当前标签胶囊 + `FlipClock.elapsed` 翻牌计时（支持超 24 小时）+ 当前时间 + 暂停/停止圆钮；暂停时计时牌降透明度并显示"已暂停"。
- **暂停/继续**：`pauseTimer` 把 `now - startTime` 累加进 `WorkEntry.accumulatedSeconds` 并记录 `pausedAt`；`resumeTimer` 把 `startTime` 重置为当前时间并清除 `pausedAt`（分段累计）；`WorkEntry.duration/liveElapsed` 统一加上累计秒数。
- **全屏计时**：点击计时牌进入 `FullscreenTimerPage`：强制横屏 + immersiveSticky + `WakelockPlus` 常亮，控制层 3 秒自动隐藏，支持暂停/继续/结束/常亮开关。
- **停止与结算**：`stopTimer` 计算时长并按标签收入模式结算（见 §5.1）。

#### 3.4.2 标签与收入模式

`TimerTag` 支持 4 种收入模式（`incomeType`）：

| 模式 | 常量 | 行为 |
|------|------|------|
| 普通 | `none` | 纯计时，不产生账目 |
| 时薪 | `hourly` | 停止时 `时长(小时) × hourlyRate` 自动生成收入 |
| 自统计 | `manual` | 停止时弹窗由用户输入本次所得，确认后生成收入 |
| 固定薪资 | `fixed` | 停止时按 `fixedSalary` 固定金额生成收入 |

- `isWork` 与 `incomeType != none` 联动，标签选中态显示星标。
- 管理：点击标签切换（计时中禁止切换）、长按编辑、标签栏 "+" 新增（长按打开管理弹窗：拖动排序、编辑、删除，至少保留 1 个）。
- 图标可选自 `IconUtils.tagIcons` 的 20 个 key。
- 落库顺序：更新 `WorkEntry`（status=completed，income）→ 创建 `FinanceEntry`（收入，`categoryId: inc_1`，描述「工作计时: 标签名」，`workEntryId` 关联）→ 刷新 Dashboard/Finance。

#### 3.4.3 打卡

- 打卡页为计时子页的 PageView 第二页。
- 未打卡：显示日期/星期与「打卡」按钮（跟随标签色）；正计时进行中时禁止打卡。
- 已打卡：显示打卡时间与实时已打卡时长，红色「结束打卡」按钮。
- 数据实现：`clockIn()` 创建 `mode='clock'` 的 `WorkEntry`（`projectName` 为当前标签名，缺省"打卡"）；`clockOut()` 记录 `endTime` 并更新今日打卡总时长。**不生成账目、不计算薪资**。

#### 3.4.4 记录管理

- 底部「今日记录」按选中日期（默认今天）列出工时与打卡；显示 `HH:mm - HH:mm/进行中`、名称（工作标签带星标）、时长；进行中时长用主题色加粗。
- 长按记录打开编辑弹窗（名称/开始/结束/收入/备注；进行中记录不可改结束时间）；非进行中行尾 × 删除（二次确认）。
- 启动时 `_checkActiveTimer()` 恢复未结束记录：`mode=='clock'` 恢复打卡状态，否则恢复计时（含暂停态）。

#### 3.4.5 工时统计（WorkStatsView）

- `WorkStatsController` 支持日/周（周一起）/月/年四种周期，可前后翻页（未来区间禁用）。
- 汇总：总时长、记录数、日均时长（按已过天数折算）。
- 图表：`DurationBarChart`（分桶：日 24 小时 / 周 7 天 / 月按天 / 年 12 月）；月视图附 `MonthDurationCalendar` 月历热力（可按时长或标签筛选）；`DonutChart` 展示标签时长占比（标签色取同名 `TimerTag.color`，打卡固定绿色，未匹配灰色）。
- 仅统计 `status == completed` 的记录，按 `startTime` 归属区间，聚合到分钟。

### 3.5 记账统计（StatsView）

- `StatsController` 支持周/月/年，可前后翻页。
- 汇总卡：收入（绿）/ 支出（红）/ 结余（负值红色），`CountUpText` 滚动。
- 「收支趋势」：`TrendChart` 双折线（收入绿、支出红），点击数据点显示「收 / 支」气泡，带揭晓动画；无数据时占位。
- 「支出构成 / 收入构成」：`DonutChart` 环形占比（从 12 点方向顺时针、带揭晓动画），图例最多 6 项，超出显示"其余 N 个分类合计"；未知分类合并为灰色"未分类"。
- 下拉刷新重算。

### 3.6 数据模型

### 3.7 本地存储

**目录**：`getApplicationDocumentsDirectory()/gongmo_data/`

| 文件 | 内容 | 保存时机 |
|------|------|----------|
| `work_entries_{年份}.json` | 该年工时/打卡记录 | 每次增删改 |
| `finance_entries_{年份}.json` | 该年账目 | 每次增删改 |
| `categories.json` | 收支分类 | 分类变更 |
| `accounts.json` | 支付账户 | 账户变更 |
| `timer_tags.json` | 计时标签 | 标签变更 |
| `invoice_profiles.json` | 发票抬头 | 抬头变更 |
| `config.json` | 轻量配置键值（见附录 A） | 立即写入 |
| `tombstones.json` | 删除墓碑 `kind:id → 删除时间(ms)` | 删除记录时 |
| `auto_queue.json` | 自动记账待处理队列（后台引擎写、主引擎消费） | 监听通知/启动处理 |
| `background.jpg` | 自定义背景图（image_picker 拷贝） | 用户选择背景时 |

**按年分片**：`_saveYearSplit` 依据 `WorkEntry.startTime.year` / `FinanceEntry.date.year` 分文件写入，并清理无数据的旧年份分片；`_loadYearSplit` 加载所有匹配 `{prefix}_{年份}.json` 的文件，单个分片损坏时跳过不影响其他年份。旧版单文件 `work_entries.json` / `finance_entries.json` 在启动时自动迁移（按 id 去重合并）后删除。

**删除墓碑**：删除记录时写入 `tombstones.json`（key 形如 `work:uuid`、`finance:uuid`、`category:uuid`、`account:uuid`、`timerTag:uuid`、`invoice:uuid`），合并时若"删除时间 ≥ 记录最后更新时间"则丢弃该记录，防止已删数据从其他设备"复活"；墓碑保留 180 天后自动清理。

**变更通知**：`StorageService.onDataChanged` 在每次落盘后触发（恢复/合并期间用 `_restoring` 标志静默），由 `SyncController` 做 6 秒防抖自动备份与 UI 刷新。`setConfig` 不触发（轻量配置），`setDataConfig`（预算）会记录更新时间戳并触发。

### 3.8 GitHub 云备份与多设备合并

**远端结构**（仓库的 `gongmo_backup/` 目录）：

| 文件 | 内容 |
|------|------|
| `index.json` | 版本、导出时间、年份列表、数量统计；`global` 段含分类/账户/标签/发票抬头/预算/墓碑 |
| `{年份}.json` | 该年份的 `workEntries` + `financeEntries` |

**配置**：

- 仓库地址经 `normalizeRepo` 归一化为 `owner/repo`，存 `config.json` 的 `github_repo`。
- Token 经 `sanitizeToken` 清洗（去空白/零宽字符/BOM）、`isValidTokenFormat` 校验前缀（`ghp_/gho_/ghu_/ghs_/ghr_/github_pat_`），存 `flutter_secure_storage` 的 `github_token`（Android encryptedSharedPreferences）。
- `last_sync`、`last_remote_sha` 存 config.json。

**推送 `pushBackup`（增量防覆盖）**：

```
读取仓库+Token → 列远端文件 sha
若 index.json 的 sha 与本机 last_remote_sha 不同（云端有新数据）
    → 先 _pullRaw 拉取远端 → StorageService.mergeRemoteData 合并到本地
→ exportDataByYear 生成年度分片 + index
→ 逐文件 PUT（带 sha 更新），记录新的 index sha
```

**恢复 `pullBackup`**：拉取 index 与全部年份分片，合并为 `restoreAllData` 的结构；`SyncController.restoreFromGithub` 用其**整体覆盖**本地（含预算），并刷新各控制器。

**自动同步**：`SyncController` 在数据落盘回调后防抖 6 秒触发 `_runAutoSync`；用 `syncSignature`（全部数据 + 预算 + 墓碑的 JSON 字符串）的哈希去重，数据无变化时跳过；失败静默，等下次数据变动重试。

**本地导出**：`exportJson` 把 `exportAllData()` 写入 `Documents/gongmo_backup_{时间戳}.json`。

**清空云端**：设置页危险操作（需输入指定文字确认），`clearRemoteBackups` 逐个 DELETE `gongmo_backup/` 下的文件。

**合并算法（`SyncMerge`）**：

- 按 `id` 取并集；同一 id 取 `updatedAt`（缺失回退 `createdAt`）较新者；时间相同保留本地。
- 墓碑优先：墓碑时间 ≥ 记录更新时间 → 丢弃。
- 墓碑合并取较晚时间；`prune` 清理 180 天前的墓碑。
- 预算按 `budgets_updated_at` / `total_budget_updated_at` 较新一方合并。

### 3.9 自动记账

**支持应用**（`AutoBookkeepingService.supportedApps`）：

| key | 应用 | 包名 |
|-----|------|------|
| `alipay` | 支付宝 | `com.eg.android.AlipayGphone` |
| `wechat` | 微信 | `com.tencent.mm` |
| `cmb` | 招商银行 | `com.cmbchina.ccd.pluto.cmbActivity` |

**架构**（后台引擎与主引擎协作）：

```
Android 通知 → NotificationsHandlerService（前台服务，specialUse）
→ autoBookkeepingNotificationHandler（顶层函数，后台引擎）
→ 解析金额/类型/商户 → 去重 → 追加写入 auto_queue.json
（主引擎）App 启动 / 回到前台 → processQueue() → FinanceRepository.save
→ onDataChanged → UI 刷新 + 自动同步
```

**解析规则**：

- 支付宝 `parseAlipay`：免密/自动扣款（含商户名）、支出（金额在前/关键词在前、兼容千分位）、退款（资金流入）、收入（收款/入账/转账）。
- 微信 `parseWechat`：向商户付款（含商户名）、已支付/支付成功、退款到账、收到他人转账/红包、收款到账。
- 招商银行 `parseNotification('cmb')`：入账 / 支出消费人民币。
- 金额需满足 `0 < amount < 1,000,000`；退款可通过"自动记录退款"开关关闭。
- 微信通知需包含"微信"来源字样，避免聊天消息误记账。

**去重**：`dedupKey = 包名|通知全文|分钟时间戳`，队列中已存在则忽略；队列容量上限 60，超出丢弃最旧。

**入账**：支出 → `categoryId='exp_5'`（其他支出），收入 → `inc_3`（其他收入）；描述「自动记账 · 商户/应用」或「自动记账 · 退款」；`notificationSrc` 标记来源，界面显示"自动"标签。

**权限与开关**：主开关 `auto_accounting`、退款开关 `auto_refund`、分应用开关 `auto_apps`（未配置默认开启）；需在系统授予"通知使用权限"（`NotificationsListener.openPermissionSettings`）。后台引擎每次启动会 `reloadConfig` 读取最新开关。

### 3.10 应用锁

- **图案**：`PatternLock` 3×3 组件，4 点起有效，自动补中间点；图案以随机 16 字节盐 + SHA-256 哈希存 `flutter_secure_storage`（`app_lock_pattern` / `app_lock_salt`），不存明文。
- **生物识别**：`local_auth`，`biometricOnly: false`（允许系统锁屏密码回退，兼容 MIUI），失败错误码映射为中文提示；设备支持性用 `canCheckBiometrics || isDeviceSupported` 判断。
- **解锁与重锁**：解锁成功 `markUnlocked()`；应用回到前台时若距上次解锁 > 20 秒且应用锁开启，跳 `/lock`。解锁页冷启动回主页、后台返回则 pop 回原页面；`PopScope` 禁止返回键绕过。
- **设置**：开关应用锁前必须已设置图案（进入 `PatternSetupPage` 返回 true）；开启时可自动启用生物识别；关闭会同时关闭生物识别；支持"修改解锁图案"。

- 持久化键：`theme_mode`、`theme_preset`、`theme_bg`。

### 3.13 每日提醒与后台常驻

**每日提醒（ReminderService）**：默认 21:00，`flutter_local_notifications` 的 `zonedSchedule` + `DateTimeComponents.time` 每天重复；使用 `inexactAllowWhileIdle` 非精确调度（避免申请精确闹钟权限）；Android 13+ 开启时先申请通知权限；配置键 `reminder_enabled/reminder_hour/reminder_minute`；时区经 `ensureTimezonesInitialized` 初始化（失败退化东八区）。

**后台常驻（KeepAliveService）**：请求忽略电池优化（`permission_handler`，10 秒超时兜底）、跳系统应用设置/电池优化列表（优先原生 MethodChannel `com.gongmo.cbq.gongmo/settings`，失败退回 `openAppSettings`）。设置页提供 4 条手动设置指引。

## 5. 关键流程

### 5.1 计时结束 → 收入结算

```
停止计时 stopTimer()
  ├─ duration = entry.liveElapsed（含暂停累计）
  ├─ 读取标签 incomeType
  │    ├─ hourly  → income = 小时数 × hourlyRate
  │    ├─ fixed   → income = fixedSalary
  │    ├─ manual  → 结束后弹窗输入本次所得
  │    └─ none    → 不产生收入
  ├─ WorkEntry → completed（income、endTime、清除 pausedAt）
  ├─ income > 0 → 创建 FinanceEntry(income, inc_1, "工作计时: 标签名", workEntryId)
  └─ 刷新 Dashboard / Finance 界面
```

### 5.2 暂停/恢复时间累计

```
暂停 pauseTimer()
  accumulatedSeconds += now - startTime
  pausedAt = now        → liveElapsed 冻结

继续 resumeTimer()
  startTime = now
  pausedAt = null       → liveElapsed = accumulatedSeconds + (now - startTime)

停止 duration = accumulatedSeconds + (endTime - startTime)
```

### 5.3 打卡考勤

```
打卡 clockIn()
  → 创建 WorkEntry(mode='clock', status=inProgress, projectName=当前标签或"打卡")
  → 显示实时打卡时长

结束打卡 clockOut()
  → endTime = now，status = completed
  → 统计今日打卡总时长（todayClockDuration）
  → 不创建 FinanceEntry、不计算薪资
```

### 5.4 启动恢复进行中记录

```
WorkController.onInit()
  → _checkActiveTimer()
      active = status == inProgress 的记录（设计上同时最多一条）
      ├─ mode == 'clock' → 恢复 isClockedIn，显示打卡中
      ├─ pausedAt != null → 恢复暂停态（冻结显示）
      └─ 否则 → 恢复运行态，_startTick() 每秒刷新
```

### 5.5 自动记账跨引擎流程

```
[后台引擎] 通知到达
  handleEvent()
    ├─ storage.init() + reloadConfig()
    ├─ 开关/应用匹配 → 解析金额 → 退款开关判断
    ├─ dedupKey 去重 → 队列上限 60
    └─ 追加写 auto_queue.json

[主引擎] App 启动 / 回到前台
  processQueue()
    ├─ 读取队列 → 清空队列文件
    └─ 逐条 FinanceRepository.save()
         → saveFinanceEntries → onDataChanged
         → 防抖 6s 自动云备份 + UI 刷新
```

### 5.6 云备份合并（多设备防覆盖）

```
pushBackup()
  ├─ 远端 index.json sha ≠ last_remote_sha（云端有更新）
  │     → _pullRaw 拉取远端 → mergeRemoteData(远端, 本地)
  │         ├─ 记录并集（updatedAt 新者胜、同时间本地优先）
  │         ├─ 应用墓碑（删除时间 ≥ 更新时间则丢弃）
  │         ├─ 预算按更新时间取新
  │         └─ 落盘（_restoring=true 不触发自动同步）
  ├─ 导出按年分片 + index
  └─ 逐文件 PUT → 保存新 index sha
```

### 5.7 应用锁生命周期

```
启动：main() → lock.init() → initialRoute /splash
  ├─ 已启用且有图案 → /lock
  └─ 否则 → /（主页）

运行：paused/hidden → 记录时间
  resumed → 距上次解锁 > 20s 且已启用 → Get.toNamed('/lock')
  （当前在 /lock、/splash 时不重复跳转）
```
