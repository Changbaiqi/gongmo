## 1. 项目概述

### 1.1 项目背景

"工墨"是一款面向自由职业者及小型团队的**工时记录与记账一体化**移动应用。区别于市面上单一功能的计时或记账工具，工墨将两者融合在同一界面：记账与计时通过底部导航无缝切换，计时模块中的"工作"标签记录自动生成收入账目。

### 1.2 核心特性

1. **记账与计时一体**：底部双页切换（记账 | 时钟），左右滑动也可切换
2. **计时模式**：可自定义标签，工作标签自动计算收入并生成账目
3. **打卡模式**：上下班打卡，自动统计每日工时（不自动计算薪资）
4. **日历视图**：月历显示有记录的日子（橙色圆点标记）
5. **快速记账**：首页右下角 + 按钮弹出快速记账表单
6. **GitHub 云端备份**（计划中）：数据同步至 GitHub 仓库
7. **多设备同步**（计划中）：通过 GitHub 仓库实现设备间同步

### 1.3 技术选型

| 类别 | 技术 | 说明 |

| 框架 | Flutter 3.x | 跨平台 UI |
| 语言 | Dart | Flutter 原生语言 |

## 3. 核心功能设计

### 3.1 HomePage 主框架

```
┌─────────────────────┐
│  AppBar: 工墨记账    │  ← 标题随 Tab 切换
│  [sync] [settings]  │
├─────────────────────┤
│                     │
│  PageView (可滑动)   │
│  ├─ 记账 Tab        │
│  │   ├─ 月历卡片    │
│  │   ├─ 收入/支出卡 │
│  │   ├─ 进行中计时   │
│  │   └─ 全部账目     │
│  └─ 时钟 Tab        │
│      ├─ 计时/打卡切换│
│      └─ 计时器/打卡页│
│                     │
├─────────────────────┤
│  记账  │  时钟       │  ← 自定义底部导航
│  (+ 加号按钮)        │
└─────────────────────┘
```

### 3.2 记账功能

- **月历**：展示当月日期，有记录的日子标记橙色圆点
- **收支卡片**：显示本月累计收入/支出
- **进行中计时横幅**：显示当前正在计时的任务和已用时间，可快速停止
- **全部账目列表**：按时间排列，颜色区分收入（绿）/支出（红），长按删除
- **快速记账**：右下角 + 按钮弹出 bottom sheet，支持输入金额、切换收支、选择分类、填写备注

### 3.3 时钟功能

页面顶部有 **计时 | 打卡** 模式切换。

#### 3.3.1 计时模式

- **标签选择**：横向滑动选择计时类型（预设：工作、学习、休息、运动、阅读）
  - 工作标签标记 ⭐，结束计时自动计算收入（hours × hourlyRate）并生成收入账目
  - 其他标签纯计时，不生成账目
- **标签管理**：长按编辑/删除，点击右侧 + 添加新标签
  - 可设置名称、是否为工作标签、时薪
- **计时界面**：
  - 空闲态：大圆形播放按钮
  - 运行态：脉冲动画圆环 + 大字秒表 + 红色停止按钮
- **今日记录**：底部列表显示今日已完成计时

#### 3.3.2 打卡模式

- 显示当前实时时间、日期、星期
- **绿色"上班"按钮**：记录上班打卡
- 已打卡后显示上班时间 + 实时已打卡时长
- **红色"下班"按钮**：记录下班打卡，自动计算上班时长
- 今日打卡记录列表：显示上班→下班时间段和时长（X小时X分钟）
- 支持一天多次打卡（上午一对、下午一对）
- **不自动计算薪资**

### 3.4 数据模型

```dart
// 工时条目
class WorkEntry {
  String id;
  DateTime startTime;
  DateTime? endTime;
  String projectName;
  String description;
  double hourlyRate;
  double? income;
  String? financeEntryId;
  WorkStatus status;  // inProgress, completed, settled
  DateTime createdAt;
  DateTime updatedAt;
}

// 账目条目
class FinanceEntry {
  String id;
  FinanceType type;  // income, expense, transfer
  double amount;
  String categoryId;
  String description;
  String? workEntryId;  // 关联工时
  DateTime date;
  DateTime createdAt;
  DateTime updatedAt;
  List<String> tags;
}

// 计时标签
class TimerTag {
  String id;
  String name;
  String icon;
  String color;
  bool isWork;       // 是否工作标签（计算收入）
  double hourlyRate; // 时薪（仅工作标签有效）
  int sortOrder;
}

// 分类
class Category {
  String id;
  String name;
  FinanceType type;
  String icon;
  String color;
  int sortOrder;
}

// 账户
class Account {
  String id;
  String name;
  double initialBalance;
  DateTime createdAt;
}
```

### 3.5 JSON 持久化

数据存储在应用私有目录 `gongmo_data/` 下：

| 文件 | 内容 |
|------|------|
| `work_entries.json` | 所有工时/打卡记录 |
| `finance_entries.json` | 所有账目记录 |
| `categories.json` | 收支分类 |
| `accounts.json` | 支付账户 |
| `timer_tags.json` | 计时标签 |

首次启动自动写入默认数据。每次增删改操作自动保存到文件。

## 4. 控制器职责

| 控制器 | Tag | 职责 |
|--------|-----|------|
| DashboardController | `dashboard` | 聚合统计：今日工时、月收支、进行中计时、日历标记日期 |
| WorkController | - | 计时/打卡核心逻辑：标签选择、计时启停、打卡上下班、收入自动生成 |
| FinanceController | - | 记账 CRUD、分类查询、月度统计 |
| SettingsController | - | GitHub 配置、分类管理 |
| SyncController | - | 同步状态、JSON 导出 |

控制器间通信：`WorkController` 和 `FinanceController` 通过 `Get.find<DashboardController>(tag: 'dashboard').refreshData()` 同步仪表盘数据。

## 5. 关键流程

### 5.1 工作标签计时

```
选择"工作"标签 → 点击播放 → 开始计时
    ↓
计时中（实时秒表 + 脉冲动画）
    ↓
点击停止 → 计算 duration
    ↓
duration × hourlyRate = income
    ↓
自动创建 FinanceEntry (type=income, amount=income)
    ↓
更新仪表盘
```

### 5.2 打卡考勤

```
点击"上班" → 记录 startTime（WorkEntry status=inProgress, projectName='打卡'）
    ↓
显示实时打卡时长
    ↓
点击"下班" → 记录 endTime → 计算 duration（WorkEntry status=completed）
    ↓
今日打卡记录列表显示并汇总总时长
（不创建 FinanceEntry，不计算薪资）
```
