# 工墨 (GongMo)

工时记录与记账一体化的 Flutter 应用：计时、打卡、记账、统计、云备份，一个 App 搞定。

## 特性

### 记账与计时一体
- 主界面底部双页切换（记账 | 时钟），支持左右滑动
- 记账页内含「记账 / 统计」子切换，时钟页内含「计时 / 统计」子切换

### 计时与打卡
- **正计时**：翻牌时钟显示，支持暂停/继续（分段累计），点击计时牌进入横屏全屏沉浸计时
- **标签收入模式**：普通 / 时薪 / 自统计 / 固定薪资，工作标签结束后自动或半自动生成收入账目
- **标签管理**：增删改、拖动排序、20 个图标可选
- **打卡考勤**：上下班打卡，实时显示已打卡时长，自动统计每日工时（不计薪）
- **记录管理**：长按修改记录（时间/名称/收入/备注），左滑删除；App 重启自动恢复进行中的计时/打卡

### 记账
- **结余卡**：本月收入/支出/结余金额滚动动画，倾斜 3D + 毛玻璃质感，随滚动翻折收缩
- **预算管理**：总预算 + 分类子预算，分段进度条与已用比例，超支变色提醒
- **账目流水**：按天分组、按月筛选、左滑修改/删除、快速记账底部表单
- **分类管理**：自定义分类名称/图标/颜色，拖动排序；内置收入 3 类、支出 5 类

### 统计报表
- **记账统计**：周/月/年收支汇总、收支趋势折线图、收支构成环形图
- **工时统计**：日/周/月/年时长趋势柱状图、标签占比环形图、月历时长热力图

### 数据同步与备份
- **GitHub 云备份**：按年份分片备份到仓库 `gongmo_backup/`，Token 加密存储
- **多设备合并**：上传前先拉取合并（并集 + 最新修改优先 + 删除墓碑），多设备互不覆盖
- **自动同步**：数据变动后防抖 6 秒自动备份，数据无变化自动跳过
- **本地导出**：一键导出完整 JSON 备份

### 自动记账
- 监听支付宝 / 微信 / 招商银行通知，解析金额自动入账，支持分应用开关
- 自动记录退款（可关闭），同笔交易去重，条目带「自动」标记

### 截屏记账
- **常驻通知卡片**：通知栏常驻自定义布局（RemoteViews），卡片内嵌「截图记账」按钮，在账单页面点按钮即截屏识别（Android 11+，不受 MIUI 折叠操作按钮影响）
- **本地离线 OCR / AI 识图可切换**：默认 ML Kit 中文离线识别（截图不出本机）；可在设置切换为 AI 视觉模型（OpenAI 兼容接口，如通义千问 VL、GLM-4V、GPT-4o），自动填好收支方向 / 金额 / 分类 / 备注，失败自动回退本地识别
- **弹窗确认入账**：自动提取金额 / 收支方向 / 商户，以「截图背景 + 浮窗」形式在当前页面上确认，分类与记账功能实时同步（支持弹窗内分类管理），关闭后自动切回原应用
- **设置管理**：设置页「截屏记账 / 识图记账」可开关常驻通知、长按拍照记账，查看并跳转开启无障碍服务授权，配置本地/AI 识别与 AI 接口
- **长按拍照记账**：长按记账页右下角 + 按钮，拍照识别账单并自动填入金额/分类/备注（识别方式与截屏记账共用）

### 安全与体验
- **应用锁**：3×3 图案锁（加盐 SHA-256）+ 指纹/生物识别，返回前台超 20 秒自动重锁
- **每日提醒**：可配置时间的记账提醒通知
- **主题**：8 套 Material 3 配色（粉白/墨绿/黑白/番茄红/海洋蓝/星夜/莫兰迪/葡萄紫）、亮暗/跟随系统、自定义背景图
- **后台保活引导**：电池优化白名单与系统设置跳转（保障通知监听常驻）

### 效率工具
- **记账侧**：发票助手（抬头管理/一键复制）、汇率计算器（实时汇率）、薪资计算器（五险一金与个税）
- **时间侧**：秒表（计次/历史）、时区显示/转换、跨时区重叠时段图

## 技术栈

- Flutter 3.x + Dart
- GetX（路由、响应式状态管理、依赖注入）
- JSON 文件本地存储（按年份分片，path_provider）
- Material Design 3（8 套配色预设，亮暗双主题）
- flutter_secure_storage（GitHub Token、应用锁图案哈希）
- flutter_notification_listener / flutter_local_notifications（自动记账监听 / 每日提醒）
- ML Kit 中文离线 OCR（原生集成，截屏账单识别，不上传）
- http（GitHub Contents API、汇率 API）、local_auth、crypto、sensors_plus 等

## 快速开始

```bash
# 安装依赖
flutter pub get

# 运行
flutter run

# 构建 APK（release）
flutter build apk --release

# 静态检查与测试
flutter analyze
flutter test
```

> Android 平台权限：通知使用权限（自动记账）、通知权限（提醒）、指纹（应用锁）、无障碍服务（截屏记账）等需在系统设置中授权。

## 项目结构

```
lib/
├── main.dart                         # 入口：初始化、全局回前台锁屏
├── app/
│   ├── routes/                       # 路由定义（17 个路由）
│   └── theme/                        # 8 套主题预设 + 主题控制器
├── core/
│   ├── constants/                    # 应用常量
│   ├── utils/                        # 日期/图标工具、时区初始化
│   └── widgets/                      # 通用组件（翻牌时钟、图案锁、倾斜卡等）
├── data/
│   ├── models/                       # WorkEntry / FinanceEntry / Category / Account / TimerTag / InvoiceProfile
│   ├── repositories/                 # WorkRepository / FinanceRepository
│   └── services/                     # 存储、GitHub 同步、合并算法、自动记账、提醒、保活
└── modules/
    ├── splash/                       # 启动页（分流锁屏/主页）
    ├── lock/                         # 应用锁（图案 + 生物识别）
    ├── home/                         # 主界面（底部双 Tab + 记账主体）
    ├── dashboard/                    # 仪表盘控制器 + 月历组件
    ├── work/                         # 时钟页（计时/打卡/工时统计/秒表/时区工具）
    ├── finance/                      # 记账控制器 + 独立记账页
    ├── stats/                        # 收支统计（趋势图/环形图）
    ├── sync/                         # GitHub 同步页与同步引擎
    ├── settings/                     # 设置页（外观/自动记账/截屏记账/提醒/GitHub/安全）
    ├── more/                         # 发票/汇率/薪资工具
    └── ocr/                          # 截屏账单识别确认弹窗
```

## 数据存储

数据保存在应用私有目录 `gongmo_data/`：

| 文件 | 内容 |
|------|------|
| `work_entries_{年份}.json` / `finance_entries_{年份}.json` | 按年分片的工时与账目 |
| `categories.json` / `accounts.json` / `timer_tags.json` / `invoice_profiles.json` | 分类/账户/标签/发票抬头 |
| `config.json` | 主题、预算、同步、提醒等配置 |
| `tombstones.json` | 删除墓碑（多设备合并防恢复） |
| `auto_queue.json` | 自动记账待处理队列 |
